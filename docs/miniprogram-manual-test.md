## 时间线与安全

- [ ] 触底分页无重复项，多次触底只产生一个请求；到底提示正确。
- [ ] 按记录内顺序预览多图；作者可确认删除，另一方没有删除入口。
- [ ] Access Token 过期后多个并发请求只刷新一次，并自动恢复页面。
- [ ] 退出登录后旧页面、首页缓存、时间线和草稿均不可见。
- [ ] 解除关系前提示历史立即不可见；解除后保留账号但旧关系内容不可见，返回键无法回到旧页面。
