# 发布候选安全审查

## 结论

未发现已提交的真实密钥、跨情侣读取或未鉴权业务路由。所有业务 API 使用 Bearer Token，并在应用层先解析当前有效情侣关系；动态编辑/删除和共同清单删除均有所有权限制。COS 上传使用短期签名和一次性授权，照片读取 URL 为短期签名。

## 已修复

- `SEC-001`（中）：HTTP 服务已有限时和 1 MiB 请求体限制，但未显式限制请求头。已在 `server/internal/bootstrap/application.go` 增加 `MaxHeaderBytes: 1 << 20` 并加入回归断言。
- `REL-001`（重要）：旧迁移命令固定执行 `000001`，无法部署第二阶段。现支持显式 `-version 1|2`，并在 README 写明顺序。
- `STATE-001`（低）：解除关系或退出后曾保留待编辑动态缓存。现在同步清除 `editingMoment`。

## 需在部署环境确认

- TLS、安全响应头与限流由 Nginx/云安全组承担，应用仓库未包含完整边缘配置。
- 微信订阅模板 ID 默认留空；缺失时功能安全降级为不可用，不影响主要写操作。
- 公共资源仍使用自增数字 ID，但所有查询同时限定有效情侣关系；后续公开分享功能应改用不可猜测 ID。
