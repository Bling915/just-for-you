# 一二阶段手工验收清单

## 准备

- 后端已依次应用 `000001`、`000002`，健康检查 `/healthz` 返回正常。
- `.env` 使用真实值且未提交；微信后台已配置 HTTPS request/upload/download 合法域名。
- 单人调试可设置 `ENABLE_SOLO_TEST=true`；双人边界必须使用两个微信测试号复验。

## 核心流程

- [ ] 登录、编辑昵称；邀请链接登录后仍能保留邀请码并完成绑定。
- [ ] 双方分别更换头像；COS 授权、PUT 或资料确认失败时旧头像不丢失，成功后所有日记卡作者头像更新。
- [ ] 单人测试标识清晰；解除关系后动态、状态、纪念日、待办、愿望和报告立即不可访问。
- [ ] 发布 0–9 张图片，查看压缩/进度/失败重试；失败图片不会产生残缺动态。
- [ ] 修改自己的动态、照片顺序、地点和发生时间；不能修改对方动态；并发修改出现冲突提示。
- [ ] 首页状态过期后不再展示；想你、抱抱、加油有节流反馈。
- [ ] 纪念日支持闰日；共同待办和愿望可由任一方完成/重开，只有创建者可删除。
- [ ] 纪念日支持置顶、倒数/累计、每年重复、封面和三种纪念相框；拒绝相册权限后可恢复并重新导出。
- [ ] 日历跨月、闰日和补记动态日期正确；地图不展示正文；月报空态和计数正确。
- [ ] 拒绝位置权限时仍可手输地点；地图无坐标记录时正常显示空态。
- [ ] 缺少订阅模板、拒绝授权或微信发送失败时，主要写操作仍成功。

## 视觉与设备

- [ ] 三个主 Tab 仍为首页、时光、我的，所有二级入口均可返回。
- [ ] 小屏设备无横向溢出；安全区、加载、空态、错误态和减少动画场景可用。
- [ ] 微信开发者工具无编译错误、WXML 警告或未注册页面。
- [ ] 无备案时按局域网真机流程验证单人模式；正式发布前再用两个微信测试号和 HTTPS 合法域名复验。
